# Бот учёта расходов (Telegram → Notion)

Пишете боту, например: `500 продукты` или `потратил 1200 на такси` —
он определяет категорию по ключевым словам и сохраняет строку в вашу базу Notion.
Если категория угадана неверно — под сообщением есть кнопки, чтобы поправить.

## 1. Создать Telegram-бота
1. Откройте в Telegram **@BotFather**.
2. Отправьте `/newbot`, придумайте имя и username.
3. BotFather пришлёт **токен** — сохраните его, он понадобится в `.env`.

## 2. Создать интеграцию Notion (без карты и биллинга)
1. Откройте [notion.so/my-integrations](https://www.notion.so/my-integrations) и войдите
   под своим аккаунтом Notion (если его нет — регистрация бесплатная).
2. Нажмите **+ New integration**.
3. Дайте имя, например `expense-bot`, выберите ваш Workspace → **Submit**.
4. На открывшейся странице скопируйте **Internal Integration Secret** — это и есть
   `NOTION_TOKEN`.

## 3. Создать таблицу (базу данных) в Notion
1. В Notion создайте новую страницу → выберите тип **Table** (Таблица) —
   это создаст базу данных.
2. Настройте колонки (свойства) с ТОЧНО такими именами и типами:
   - **Описание** — это будет title-колонка (переименуйте колонку "Name" в "Описание").
   - **Сумма** — тип **Number**.
   - **Категория** — тип **Select**.
   - **Месяц** — тип **Select**.
   - **Дата** — тип **Date**.
3. Названия и типы должны совпадать один в один — от них зависит код бота
   (если хотите другие имена — просто поменяйте константы `PROP_*` в начале `bot.py`).

### Как устроена таблица
Бот не пишет отдельную строку на каждую покупку. Вместо этого на каждую пару
**месяц + категория** есть ровно одна строка, и сумма в ней накапливается.
Например, если за сентябрь вы 5 раз тратили на «Продукты», в таблице будет
одна строка «Продукты — Сентябрь 2026» с общей суммой всех пяти покупок.

Когда наступает новый месяц, для него автоматически заводятся новые строки
(с новым значением в колонке «Месяц») — старые строки прошлых месяцев бот
больше не трогает, они остаются как есть.

Чтобы удобно смотреть по месяцам — откройте таблицу в Notion, нажмите
**+ Add view** (или измените текущий вид) → **Group by** → выберите свойство
**Месяц**. Тогда строки будут визуально сгруппированы по месяцам, и всего
за год их накопится до 12 групп.

## 4. Дать интеграции доступ к таблице
1. Откройте вашу таблицу в Notion.
2. Нажмите **•••** (три точки) в правом верхнем углу страницы.
3. Выберите **Connections** (или "Add connections") → найдите вашу интеграцию
   (`expense-bot`) → подключите.
4. Скопируйте **ID базы данных** — это часть адреса страницы в браузере,
   32-значная строка после последнего `/` и до знака `?`:
   ```
   https://www.notion.so/workspace/ВОТ_ЭТО_ID?v=...
   ```

## 5. Настроить проект
1. Скопируйте `.env.example` в `.env` и заполните:
   ```
   TELEGRAM_BOT_TOKEN=токен_от_BotFather
   NOTION_TOKEN=секрет_интеграции_Notion
   NOTION_DATABASE_ID=ID_базы_данных
   ```
2. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```
3. Запустите бота:
   ```
   python bot.py
   ```
4. Напишите боту в Telegram `/start`, затем что-нибудь вроде `300 кофе`.

## 6. Настроить свои категории
Откройте `bot.py`, найдите словарь `CATEGORIES` в начале файла — там для каждой
категории список ключевых слов. Меняйте, добавляйте, удаляйте как удобно.
Если слово не найдено ни в одной категории — трата попадёт в «Прочее».

Важно: значения категорий в Notion-свойстве **Категория** (тип Select) создаются
автоматически при первой записи с новым названием — вручную заранее их заводить
не обязательно.

## 7. Деплой на Railway (чтобы бот работал круглосуточно)

Локальный запуск (`python bot.py`) работает, только пока открыт компьютер/терминал.
Railway — облачный хостинг, который держит процесс запущенным постоянно,
карта не требуется на бесплатном стартовом периоде.

### Шаг 1. Залить код на GitHub
1. Создайте новый репозиторий на [github.com](https://github.com) (можно приватный).
2. Загрузите туда `bot.py`, `requirements.txt`, `Procfile`.
   **`.env` заливать не нужно** — секреты передаются отдельно через Railway.

### Шаг 2. Создать проект в Railway
1. Зайдите на [railway.app](https://railway.app), войдите через GitHub.
2. **New Project → Deploy from GitHub repo** → выберите репозиторий.
3. Railway сам найдёт `Procfile` и запустит `worker: python bot.py`.

### Шаг 3. Добавить переменные окружения
Во вкладке **Variables** добавьте:

| Переменная | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |
| `NOTION_TOKEN` | секрет интеграции Notion |
| `NOTION_DATABASE_ID` | ID базы данных |

### Шаг 4. Проверить
1. Дождитесь статуса *Success* во вкладке **Deployments**.
2. В **Logs** должна появиться строка `Бот запущен`.
3. Напишите боту `/start`, затем `300 кофе` — строка должна появиться в Notion.
