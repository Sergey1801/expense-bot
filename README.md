# Бот учёта расходов (Telegram → Notion, сводная таблица)

Таблица устроена как в вашем примере из Google Таблиц: **строки — фиксированные
категории**, **столбцы — месяцы**. Бот сам добавляет столбец нового месяца,
когда он наступает, и суммирует туда все траты этой категории за месяц.
Прошлые месяцы (прошлые столбцы) бот больше не трогает.

Категории: **Света, Ипотека, Еда, Машина, Развлечения, Магазины, Путешествия,
Ариша, Разное**. Бот сам определяет категорию по словам в описании траты.

## 1. Создать Telegram-бота
1. Откройте в Telegram **@BotFather**.
2. Отправьте `/newbot`, придумайте имя и username.
3. BotFather пришлёт **токен** — сохраните его, он понадобится в `.env`.

## 2. Создать интеграцию/токен Notion
1. Откройте Developer Portal Notion: `app.notion.com/developers` (раздел может
   называться "Developer tools" или "My integrations" — в зависимости от версии
   интерфейса).
2. Перейдите на вкладку **Personal access tokens** → **+ New token**.
3. Дайте имя, например `expense-bot`, выберите workspace, включите доступ
   к Notion API → сохраните.
4. Скопируйте токен (начинается с `ntn_` или `secret_`) — это `NOTION_TOKEN`.
   Персональный токен работает от вашего имени, отдельно "делиться" базой
   с интеграцией не нужно.

## 3. Создать таблицу (базу данных) в Notion
1. В Notion создайте новую страницу → выберите тип **Table** (Таблица).
2. Переименуйте колонку **Name** в **Категория** — это единственная колонка,
   которую нужно создать вручную. Остальные колонки (по одной на каждый месяц)
   бот добавит сам, когда понадобятся — руками их заводить не нужно.
3. Скопируйте **ID базы данных** из адресной строки браузера — 32-значная
   строка перед знаком `?` в ссылке на таблицу.

## 4. Настроить проект
1. Скопируйте `.env.example` в `.env` и заполните:
   ```
   TELEGRAM_BOT_TOKEN=токен_от_BotFather
   NOTION_TOKEN=токен_из_Notion
   NOTION_DATABASE_ID=ID_базы_данных
   ```
2. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```
3. Запустите бота:
   ```
   python bot.py
   ```
   При первом запуске бот сам создаст 9 строк-категорий в таблице — даже
   до того, как вы отправите первую трату.
4. Напишите боту в Telegram `/start`, затем что-нибудь вроде `300 еда`.

## 5. Как выглядит "Итого"
Столбец с суммой по всем категориям за месяц (как в вашем примере) — это
встроенная функция Notion, а не отдельная строка от бота:
1. Откройте таблицу, наведите на низ нужного столбца месяца.
2. Нажмите на появившуюся строку **Calculate** внизу колонки → выберите **Sum**.
3. Notion покажет сумму по всем строкам этого месяца — аналог строки "Итого:"
   из вашего примера. Настраивается один раз на каждый столбец месяца.

## 6. Категории и ключевые слова
Список категорий фиксированный и задаётся в словаре `CATEGORIES` в начале
`bot.py`. Если бот определяет категорию неверно — допишите туда ключевые слова.
Также после каждой записи бот показывает кнопки, чтобы вручную перенести
сумму в правильную категорию, если авто-определение ошиблось.

## 7. Деплой на Railway (чтобы бот работал круглосуточно)

### Шаг 1. Залить код на GitHub
1. Создайте репозиторий на [github.com](https://github.com) (можно приватный).
2. Загрузите `bot.py`, `requirements.txt`, `Procfile`. `.env` не заливайте.

### Шаг 2. Создать проект в Railway
1. [railway.app](https://railway.app) → войдите через GitHub.
2. **New Project → Deploy from GitHub repo** → выберите репозиторий.

### Шаг 3. Переменные окружения
Вкладка **Variables**:

| Переменная | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |
| `NOTION_TOKEN` | токен Notion |
| `NOTION_DATABASE_ID` | ID базы данных |

### Шаг 4. Проверить
**Deployments** → статус *Success*, в **Logs** — строка `Бот запущен`.
Напишите боту `/start`, затем `300 еда` — сумма должна появиться в таблице
Notion в столбце текущего месяца, в строке «Еда».
